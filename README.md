## 为什么选择言录

从线上会议到现场访谈，把完整记录、自己的想法和下一步行动放在一起。

- **随手控制录音。** 快速沿用上次会议配置；最小化或隐藏主窗口后，可通过菜单栏／托盘与悬浮胶囊控制录音、查看字幕和笔记。
- **一次修正多处。** 在逐字稿、笔记和纪要中预览、选择并批量替换文字，支持撤销；录音时可将规则应用到本场后续字幕。
- **跟上每一句。** 实时转写支持 30+ 种语言，可配合翻译与悬浮字幕，专注交流也能回看内容。
- **留住真正重要的事。** 一边听一边记，让 AI 帮你提取决定与待办；笔记和纪要都能继续编辑。
- **把会议室装进口袋。** 手机随身录音、标记重点，回到电脑继续转写与整理；也能直接作为电脑的麦克风。
- **让记录掌握在自己手中。** 无需账号，语音在自己的电脑识别。支持离线处理，也可选择自己的在线 AI 服务。

## 开始使用

1. **准备好言录。** 安装电脑端，在 **设置 → 模型库** 下载适合会议语言的识别模型。
2. **录下这次对话。** 新建会议，选择麦克风、系统声音或两者；已有录音也能直接导入。
3. **带走清晰的结果。** 跟随转写记下重点，会后整理纪要，将决定与待办编辑、导出并分享。

手机连接与使用方法见[手机指南](mobile/README.md#手机会议与桌面联动)。

## 从对话到行动

### 听得专注，也记得完整

会议的实时转写与笔记并排显示，原话与想法随时对照。写下自己的判断，让 AI 帮你梳理决定、待办和未解决的问题；每条建议由你决定是否采纳。

### 收起窗口，继续专注

悬浮录音胶囊让录音状态、时长与暂停控制始终在手边。展开可查看实时字幕与翻译、浏览笔记并采纳 AI 建议；支持固定面板，保存失败时可直接重试。点击言录图标即可返回当前会议。

![悬浮录音胶囊：字幕、笔记、暂停与保存状态](docs/assets/showcase/desktop/zh/capsule.gif)

### 把讨论变成可执行的计划

把长篇讨论整理成要点、决定与下一步行动。纪要是一份可以继续修改的文档，方便补充负责人、核对细节，再发给团队。需要回到原话时，逐字稿和录音就在同一场会议里。

![可编辑的会议纪要：摘要、决定与行动项](docs/assets/showcase/desktop/zh/summary.gif)

### 让每次对话都能找回来

按项目与团队归入工作区，通过标题、逐字稿、说话人和标签找到过去的讨论。会后精修可区分说话人，让回顾更清楚。文字与笔记可导出为 **Markdown、TXT、JSON、SRT、DOCX 或 PDF**，录音可导出为 **WAV**。

![会议库与工作区导航](docs/assets/showcase/desktop/zh/library.gif)

提供中文、英语、西班牙语、日语、韩语、法语、德语和俄语界面。

## 用手机录音

在采访现场、课堂或会议室，用手机收好声音与灵感，再交给电脑整理。

| 场景       | 使用方式                                                           |
| ---------- | ------------------------------------------------------------------ |
| 随身记录   | 手机离线录音，随手记笔记、标记重点；之后上传到自己的电脑完成转写。 |
| 边录边看   | 手机发起会议，由同一局域网的电脑识别，转写与笔记回传到手机。       |
| 会议室收音 | 手机放在发言者身边作为电脑麦克风，在电脑控制录音、查看转写与笔记。 |

## 你的记录，留在你的设备

- **本机处理。** 语音识别与说话人处理在自己的电脑运行。下载所需模型后，AI 笔记、纪要和翻译也可离线完成。
- **本地连接。** 手机与电脑通过局域网 HTTPS 通信。Brevia 不运营会议云存储或跨网中继，不会自动将会议上传给开发者。
- **按你的选择使用 AI。** 选择在线 AI 时，相关转写和笔记文字会发送给所选服务商，AI 请求不发送原始录音。详见[隐私政策](https://brevia.work/privacy.html)。

## 技术架构

- **桌面端：** Electron + JavaScript，界面使用 HTML 与 Tailwind CSS。
- **本地处理：** Python Worker 调度音频与模型，MLX / sherpa-onnx 负责语音推理，llama.cpp 运行本地 AI。
- **手机端：** Flutter + Dart，共用 iOS 与 Android 界面及录音流程。
- **存储与连接：** SQLite 保存电脑端会议记录，手机与电脑通过局域网 HTTPS 同步。

## 常见问题

### 没有互联网也能用吗？

可以。下载所需模型后，电脑端转写和本地 AI 可离线运行。手机独立录音不需要电脑，也不需要账号；手机转写需要已配对电脑，但同一局域网连接不依赖互联网。在线 AI 需要互联网。

### 应该下载哪些模型？

先下载适合会议语言的推荐识别模型。需要笔记和纪要时再添加本地 AI 模型，需要翻译时添加翻译模型。模型库会显示下载大小；性能较弱的电脑可优先选择较小的 AI 模型，不必下载全部模型。

### 录音和数据存在哪里？

电脑端默认存放在 `~/brevia`，模型与录音文件夹可在首次设置时选择，之后在设置中更改。手机录音和缓存文字保存在应用内；删除手机副本不会删除电脑副本。卸载手机应用会清除其本地数据，请先导出或同步尚未上传的录音。

### Windows 提示 SmartScreen 怎么办？

先确认安装包来自官方[发布页面](https://github.com/zerolovesea/Brevia/releases)，信任该下载后再选择「更多信息 → 仍要运行」。

### 为什么手机连接不上电脑？

确认两台设备在同一可互通局域网，电脑已唤醒并打开 Brevia，且已允许本地网络和防火墙访问 TCP 43187。访客 Wi-Fi 隔离、VPN 或电脑休眠可能影响连接。扫码不可用时可输入电脑显示的地址和 PIN；更多排查见[手机指南](mobile/README.md#手机会议与桌面联动)。
