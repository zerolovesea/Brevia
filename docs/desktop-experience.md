# 桌面体验与后台运行

更新：2026-10-20。对应本机 `output/uiux-next-version-2026-10-20/` 的设计稿与 `output/oats-interaction-reference/guide.md`。本轮实施桌面页面、独立录音胶囊、悬停预览、通用设置与菜单栏／托盘；设计 PNG 和实际截图均位于 Git 忽略的 `output/`，仓库不保证包含这些本机文件。

## 使用与行为

| 入口         | 实际行为                                                                                                                                                                                                   |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 快速录音     | 首页、侧栏与菜单栏读取最近已保存的非示例会议，沿用语言、识别模型、说话人数、翻译目标与工作区；来源固定为麦克风＋系统音频。首次使用默认多语言混说。正常启动不经过设置页，缺必要模型时才进入准备页并明确提示 |
| 开始录音     | 首页与侧栏均提供入口，保留完整的会议、工作区、模型和采集配置路径；导入音频入口独立保留                                                                                                                     |
| 实时会议     | 时间戳窄列、原译文成组、临时尾段与确认正文区分；查找与替换使用带悬停提示的纯图标，与各自面板标题同排，不再单占工具行。AI 建议位于笔记下方，正文继续可编辑                                                  |
| 会后纪要     | 复用分节阅读布局，详细讨论可展开；保留编辑、复制、导出和播放器。已有纪要不会因重新生成而被提前清空                                                                                                         |
| 等待纪要模型 | 有效的本地 AI 配置缺模型时，展示录音已保存与等待模型，保留模型库、逐字稿入口。模型就绪后使用已有会话内队列续跑，重复刷新不重复生成                                                                         |
| 浏览其他页面 | 恢复原有侧边栏会议卡片，显示当前采集会议、录制／暂停状态、计时与返回会议入口；历史会议播放器保持独立，不再用右下浮条覆盖正文                                                                               |
| 最小化／隐藏 | 有活动会话且启用自动胶囊时，显示独立胶囊；主窗口保留，音频采集上下文不销毁，关闭后台节流                                                                                                                   |
| 胶囊悬停     | 约 250ms 展开轻半透明面板，字幕／AI 笔记共用位置；跨间隙保持展开，离开整个区域约 350ms 收起。支持固定、Esc、点击入口和键盘页签                                                                             |
| 字幕阅读     | 上翻停止跟随，字幕区右下角出现下箭头，点击回到最新并恢复跟随；正文独立滚动，页签固定，不再单设底栏。真实临时尾段使用行内旋转图标表示识别中，暂停后隐藏图标；无实时字幕时沿用现有异常说明                   |
| AI 笔记      | 展示当前待采纳建议和本场笔记，无建议时不显示占位提示，分析期间只显示旋转图标；已有笔记继续保留。复用主窗口采纳／忽略；采纳写入失败保留建议，重试不重复追加                                                 |
| 返回会议     | 显式恢复主窗口并定位当前录音；普通状态更新使用 `showInactive()`，不主动激活主窗口                                                                                                                          |
| 结束         | 复用主窗口收尾，采集停止后电平停用；保存失败保留重试，成功后胶囊短暂确认再收起。手机异步保存未完成时不允许把退出当作成功                                                                                   |

实时字幕、笔记、计时和录音控制继续由现有会话拥有。`electron/desktop-controller.js` 只负责窗口、偏好、原生菜单与动作转发；胶囊不能直接调用录音、偏好保存或任意主窗口 IPC。动作携带会话身份，建议另带建议 ID，迟到动作不得操作下一场会议。

## 设置与退出

设置位于通用页，新增关闭主窗口行为、图标显示时机、自动胶囊。macOS 使用菜单栏，Windows 使用托盘。偏好保存成功后生效；入口创建失败不隐藏主窗口。

新文件 `<Brevia 数据目录>/desktop-preferences.json` 只保存桌面窗口偏好：`closeBehavior` 为 `quit`／`hide`，`trayVisibility` 为 `always`／`background`，`autoCapsule` 为布尔值。默认关闭即退出，图标始终显示，自动胶囊开启。旧 `capsuleOnTop` 字段仍可读取以兼容偏好文件，胶囊固定悬浮，设置不再显示置顶与重置位置入口。旧会议、模型配置、手机协议和其他持久化字段不改名、不迁移。

选择隐藏时，关窗继续录音，可从菜单栏／托盘恢复；真正退出使用菜单项或系统退出操作。录音中先显示与设计稿对齐的品牌确认窗，展示会议名、保存后果与“继续录音／结束并退出”。仅隐藏行为开启时说明后台录音。渲染进程不可用时回退原生确认窗。确认后等待保存，不再以旧的 8 秒等待结束作为成功依据。保存失败或有尚未处理的笔记／纪要／字幕编辑时保留窗口与恢复入口。

手动显示／隐藏胶囊只影响本次会话，不修改自动显示偏好。新会话重新应用偏好；返回主窗口仅收起自动出现的胶囊。胶囊默认显示在当前屏幕工作区底部居中，距工作区底边 32px，避开 Dock／任务栏；悬停预览向上展开。胶囊可见尺寸缩至 320×56px（原 544×68px）；暂停与结束采用 34px 纯图标按钮，悬停和辅助技术保留操作名称。展开面板仍宽 440px，正文使用 15px 字号，屏幕边缘展开时保持胶囊锚点。六点握柄与胶囊主体（标题、波形、计时与空白处）按下移动超过 3px 即拖动，暂停／结束保持独立点击；点击 Logo 返回应用，标题和空白不触发返回，不另设箭头按钮，展开面板也不再重复显示“在主窗口查看”。拖动松手不会触发返回或展开；屏幕底部向上展开并校正工作区边界。位置仅在当前进程内保留。

## 动效与实际边界

复用 `frontend/motion.js` 与 `motion.css`：按下 80ms、反馈 120ms、浮层进入 220ms、退出 140ms；字幕正文不整页淡入，页签切换不重建滚动容器。真实电平按约 80ms 上限单独转发，条高使用 75ms 线性平滑；暂停、保存和无新输入时不伪造活动。

减少动态效果时移除相应动画，保留状态文案；减少透明度时面板回退实色。面板采用约 92% 表面色和 CSS 背景模糊；跨原生应用的实际背景模糊能力取决于系统，不能把静态概念图当作已验证的原生材质效果。

本场笔记预览呈现标题、项目符号和纯文本，完整富文本、表格和图片编辑仍在主窗口。胶囊最多预览最近 80 个字幕段落，完整历史通过主窗口查看。没有为设计图中的“已采纳”新增历史持久化。

设备采集错误继续沿用现有错误处理与自动收尾，不能声称本轮已经实现断开后的无缝换设备。菜单栏／托盘是真实原生菜单，文字、间距与平台快捷键不逐像素照搬设计图片。通用设置在宽窗口保留完整主导航，窄窗口保留图标导航；短窗口滚动，不缩小字号。会议库按日期分组，使用紧凑的文档行与悬停表面，移除逐行分隔线及标签占位展示；保留手机来源标记与原有存储标签。

本轮等待队列保留在进程内；跨重启恢复、密钥存储等架构计划另行实施。没有新增手机或官网功能，也没有更改发布版本或提交应用商店。
