# Brevia 全量动效设计与实现覆盖

2026-10-17 · Motion Design System 1.4

[统一规范](motion-design.md) · [源码控件检查](../scripts/motion-inventory.mjs)

本文件把“统一规则”落实到每个页面的交互决定。控件清单扫描全部自有桌面、手机和官网交互源码，实时识别控件声明及所属规则，记录源码位置以便错误定位；适用状态与减少动态效果方案见下表。动态生成的列表项、工具栏项和模型选项沿用其组件声明的规则，不按数据条数重复统计。

**实现范围**：桌面 `motion.css/js` 接入应用入口与悬浮字幕；手机 `design_system.dart` 及所有 7 处底部层调用；官网生产入口的操作反馈与全部既有演示页面。业务能力、协议、持久化字段、录音和保存逻辑保持原职责。静态扫描只验证控件分类，不能替代异步控制器审阅或端到端测试；验证范围在文末单列。

## 每个控件如何决定

所有入口必须命中以下九类之一，不能留“以后补动画”。其中“直接更新”是有意设计，而不是遗漏。`node scripts/motion-inventory.mjs` 在测试中直接扫描当前源码并检查规则，扫描结果不写入生成文件；只有明确的基础反馈才能覆盖未注册的新实例，业务结果仍由原控制器负责。

| 规则       | 控件                                           | 适用状态与决定                                                                                                                      |
| ---------- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| control    | 普通按钮、图标操作、主操作、批量动作           | 默认静态；Hover 120ms；按下 80ms；离散控件可缩放、释放 180ms 轻回弹；焦点即时；Disabled / Busy 不缩放。行、卡片和文本按钮不整块弹跳 |
| navigation | 导航、设置分类、标签、工作区、页内锚点         | 同级正文即时 / 指示180ms；父子 280/180ms；页内 120ms；选择指示 180ms。原生导航保持平台过渡。减少动态效果直接切换                    |
| field      | 搜索、标题、备注、路径、参数、供应商密钥等输入 | 输入、清除、光标、校验即时；仅颜色 / 边界 120ms。错误显示原因，不移动或抖动输入框。密码显示与 Markdown 切换不影响草稿               |
| choice     | 复选、单选、开关、分段选择                     | 值立即更新；底色 / 滑块 120–180ms；禁用不响应；真实请求失败恢复实际值。减少动态效果直接就位                                         |
| range      | 播放进度、音量、参数滑杆                       | 手柄跟手无延迟；键盘改变即时；真实进度允许最多 120ms 插值；无确定进度不伪造数字                                                     |
| disclosure | 菜单触发、展开说明、折叠记录                   | 菜单进入 160ms、关闭最多 100ms；操作立即生效；原生自动关闭或触发跳转时允许直接关闭。文档披露只改变必要布局，不做长高度动画          |
| external   | 下载、GitHub、系统设置、分享、安装链接         | 120ms 颜色或透明度反馈；交给目标应用 / 平台导航。不制造网站内 Loading 或假成功                                                      |
| drag       | 滑动删除、拖动与自定义手势                     | 立即跟手，松开 140ms 吸附；取消回原位；不由动效触发删除。减少动态效果保留直接手势控制                                               |
| native     | ListTile、原生选择菜单、下拉与系统控件         | 沿用 Material / Cupertino 的选择、焦点与触控反馈；公共主题约束尺寸、颜色与按钮内容动效，不覆盖系统交互手势                          |

异步入口只在确有请求时使用 Loading → Success / Error。开始时立即显示可感知的忙碌状态，结果到达时立即更新；不得为了动画补一个延时。失败保留输入、提供原有重试；不能给“取消”“返回”“忽略”等即时动作强加四态流程。未实现某种业务状态的按钮明确记为不适用。

## 中断、成功、失败与减少动态效果

- 桌面导航：业务清理串行，尚未开始的旧导航由最新意图替代；动画不参与等待队列。已经开始的保存、释放预览等业务不被动效取消。
- 页面返回：保留真实DOM中的滚动位置，尽可能回到原触发项；切标签恢复当前标签焦点，不让已替换按钮成为失联焦点。
- 弹窗：进入220ms，退出140ms；设置整页不缩放。原有焦点约束与背景inert保持。快速重开取消旧退出；删除确认仍默认取消。
- 菜单：退出当帧变为inert，随后最多100ms淡出；重开取消旧回调。系统原生自动关闭不强行延迟。锚定定位不叠加transform。
- 保存、配对、下载、录音、翻译：业务控制器决定状态，动效层不调用接口或持久化；失败保留原内容和重试路径。
- 减少动态效果：Web清理所有正在执行的公共动效并落终态，CSS关闭空间运动与循环；手机按钮空间反馈 / 内容 / 底部层使用零时长，原生选择反馈与路由淡化按平台保留，返回手势保留；未知进度停止循环但仍有阶段文字。
- 窗口隐藏：Web暂停CSS循环并结束有限过渡，不滞留半透明状态；原有引导 / 官网时间轴保持各自可见性暂停机制。
