# Brevia 启动动效

气质：沉静、清晰、流畅。用途：应用启动，1500ms 单次播放。
复用唯一品牌 SVG（505×160），保留原始几何和颜色，无描摹误差；mark 为方形底及内部字形，wordmark 为固定字形。

| 阶段   | 时间        | 动作                             |
| ------ | ----------- | -------------------------------- |
| 预备   | 0–300ms     | 标记渐现、轻微蓄势               |
| 主动作 | 300–1050ms  | 标记落位，内部字形自上而下显现   |
| 收稳   | 1050–1500ms | 标记 1% 微超调回正，字标延后结束 |

应用 Staging、Slow In/Out、Timing、Follow Through、Appeal。使用 literal cubic-bezier；不变形字形，无交叉描边交接。系统减少动态效果时直接静态展示。桌面等待实际动画完成并继续等待后端；手机使用同一时长和阶段，保留本地初始化重试。

## 验证记录

直接复用源矢量：IoU 1.0，source-only / render-only 均为 0。放大图检查通过；无新增曲线或描摹节点。相同浏览器、视口和 DPR 的 static 与 1500ms 最终帧像素差为 0。500/700/900ms 探针确认非线性缓动生效，1000–1120ms 连续性扫描未发现 stall+pop。帧图无裁切。

手机字形使用同一源路径的 Canvas 表达，字标保持现有品牌资源；未新增运行依赖。本机 Flutter SDK 缺失，尚未执行手机静态分析、格式工具和 widget 测试。
