# 全局快捷键设计

对应 [Issue #14](https://github.com/zerolovesea/Brevia/issues/14)。先完成此设计，再实现桌面端；手机端、录音 Worker 与会议存储协议不变。

## 行为与边界

- 默认开始／结束键为 `Alt+CommandOrControl+R`（macOS 为 ⌥⌘R），暂停／继续键默认关闭。设置 → 通用增加快捷键区，支持录制组合键、清除、恢复默认。
- 空闲时复用快速录音；录音或暂停中复用结束并保存；保存失败时同键重试保存。暂停键仅在当前来源支持暂停且正在录音／暂停时有效。
- 初始化未完成、已有录音操作待确认、启动或保存中忽略重复按键。操作完成后短暂防抖，避免连按误结束新录音。
- 正常后台启动、暂停与结束不显示或聚焦主窗口。菜单栏已有录音标记、托盘状态与非激活胶囊负责反馈；缺模型、权限或保存错误时显示主窗口并报告错误。应用必须运行，系统授权提示仍由操作系统决定。
- 快速录音继续读取最近非示例会议的语言、模型、说话人数、翻译目标和工作区；补充记忆最近成功启动的录制来源。旧安装默认麦克风＋系统声音。手机来源未就绪时明确报错，不静默切换来源。

## 架构与兼容

`globalShortcut → DesktopController → desktop.action → 主窗口已有录音函数 → desktop.complete / desktop.publish`。

- `electron/desktop-controller.js` 管理注册、回收、操作锁及托盘按键显示，继续由主窗口独占采集。应用 ready 后、主窗口发布首个状态时注册；退出和窗口销毁时释放。
- `desktop-preferences.json` 只增加有默认值的字段：`recordingShortcut`、`pauseShortcut`、`lastCaptureMode`。保留旧字段与默认关闭行为，使用既有原子写入。保存串行化；修改只提交变更字段，避免来源记忆与设置互相覆盖。
- 新按键先尝试注册，再写配置；注册或写入失败恢复原绑定与偏好。禁止两个动作使用同一组合键。启动注册失败要可见提示，不覆盖用户配置。
- `main.js` / `preload.js` 只补充经过主窗口信任校验的桌面 IPC：记忆成功采集来源、快捷键录制期间暂停监听。主进程验证组合键格式与来源枚举。
- 快捷键编辑期间临时暂停全局监听；完成、取消、失焦、窗口切走、渲染器退出或超时后恢复，避免录制旧快捷键时误触发录音。编辑仅接受带 Ctrl／Alt／Command 的字母、数字或功能键。
- `frontend/app.js` 保留快速录音和普通录音的共享启动路径；所有成功激活录音的路径记忆实际来源，失败不更新。后台快捷键传递标志，只有需要人工处理时请求显示主窗口。
- 设置复用 `renderDesktopPreferences` 与现有 `flow-select` 下拉样式、菜单定位和设置行布局。与相邻设置保持相同的行高、控件宽高和对齐；macOS 使用符号键帽，Windows 使用 Ctrl／Alt 等文字键帽，空值显示“未设置”。菜单提供录制、清除和恢复默认；录制提示仅在编辑时替换该行说明，正常状态不显示保存成功页脚。新增文案补齐八种语言，不引入组件框架或依赖。

## 验证

- 控制器测试：旧偏好兼容、成功修改、冲突与重复绑定、写入失败回滚、清除、释放、初始化保护、防重入、空闲／录音／暂停／保存／失败状态、后台不抢焦点、编辑暂停恢复。
- 界面测试：最近来源复用、缺模型进入准备页、手机来源不可用、录制按键解析与取消／清除、按键编辑保存错误恢复。
- 按贡献规范运行 `npm run format:check` 与 `npm test`，区分既有失败与本轮回归。
- 真机验收：macOS 26 与 Windows，前台其他应用、全屏会议、隐藏／最小化、首次权限、按键冲突与长录音保存。自动化不能代替系统级焦点、权限和真实音频验收。
