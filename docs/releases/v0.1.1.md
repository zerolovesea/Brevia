# Brevia v0.1.1

Brevia v0.1.1 improves local transcription choices, meeting management, and the desktop layout.

## Highlights

- Added FireRedASR2 CTC Chinese/English and FunASR Nano as downloadable post-meeting refinement models; the Chinese default now uses FunASR Nano.
- Added Reverb + 3D-Speaker as a diarization option and made the refinement menu read directly from the installed model catalog.
- Improved compact-window behavior so the meeting setup form scales into the available workspace instead of being clipped.
- Fixed meeting-library action menus: they now stay above the scroll area and open upward when there is not enough room below.
- Kept the refinement model menu above the transcript/sidebar boundary, and refined sidebar spacing and startup branding.
- Added a Windows x64 installer alongside the Apple Silicon macOS DMG.

## Installation notes

These are unsigned development builds. macOS may require **System Settings → Privacy & Security → Open Anyway**. Windows may show a Microsoft Defender SmartScreen prompt; choose **More info → Run anyway** only after verifying the download came from this release.

The packaged app does not yet include a portable Python runtime or speech-model dependencies. Install the Python requirements from a source checkout before relying on local transcription, then download the models you need from Brevia's model library.
