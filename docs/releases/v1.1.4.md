# Brevia v1.1.4

## Improvements

- Improved live-meeting responsiveness by moving more recording and refinement work off the critical path.
- Made recording recovery more reliable: manifests are checkpointed during recording, WAV handles are reused, and recovered duration is read from the recorded audio.
- Improved post-meeting refinement around overlapping decoding windows, number fragments, and interrupted restarts for cleaner transcripts.
- Isolated AI Assist sidecar cancellation so stopping or switching one task does not interrupt unrelated inference work.

## Fixes

- Ignore late audio frames while a meeting is stopping for system sleep, preventing stale worker errors.
- Prevent alphanumeric identifiers such as `A1` and `A2` from being treated as numeric ASR corrections.
- Disable meeting-note generation while recording, avoiding concurrent processing conflicts.
- Publish direct release download links after a release is created.

## Documentation

- Refreshed README demo media and screenshots.
