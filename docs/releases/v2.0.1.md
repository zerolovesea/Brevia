# Brevia v2.0.1

修复 Windows 应用内更新在点击「允许」后安装向导不可见的问题。

Fix the Windows in-app updater hiding the installation wizard after administrator approval.

## 升级说明 / Upgrade notes

- Windows 正式版 v1.4.3 和 v1.4.5 均可直接更新到 v2.0.1。保存录音并等待后台任务结束，然后点击「检查更新」。允许系统提示后，按安装向导继续，已有会议、录音和模型会保留。<br>On Windows, official v1.4.3 and v1.4.5 installations can update directly to v2.0.1. Save your recording and wait for background tasks to finish, then select Check for updates. Approve the Windows prompt and continue in the installer. Your meetings, recordings and downloaded models carry over.
