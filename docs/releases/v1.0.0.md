# Brevia v1.0.0

Brevia 1.0 is the first production release of the local-first meeting memory app.

## Highlights

- Added browser-based PDF export for meeting notes and transcripts.
- Improved transcript, summary, audio-export, and import-processing reliability.
- Refined the meeting interface and localized copy across supported languages.
- Expanded the offline model library and meeting workflow documentation.

## Downloads

- **macOS (Apple Silicon):** `Brevia-1.0.0-arm64.dmg`, signed with Developer ID and notarized by Apple.
- **Windows x64:** `Brevia-1.0.0-x64-setup.exe`.

## Data compatibility

Existing meetings, recordings, downloaded models, configurations, summaries, and voice profiles remain in `~/brevia`.
