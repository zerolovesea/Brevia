# Brevia v0.1.11

Brevia v0.1.11 improves first-run setup, imported-recording processing, offline model selection, and multilingual meeting workflows.

## Highlights

- Added a guided, step-by-step onboarding flow for microphone and screen/system-audio permissions, with live status feedback and direct access to the relevant macOS approval screen when required.
- Imported recordings now use the existing offline speaker diarization and can match registered voiceprints instead of assigning every segment to the local user.
- Expanded the offline model library with download size, supported languages, compute backends, installed state, and capability tags. TEN VAD is no longer offered.
- Fixed incomplete interface localization, including recording controls, VAD labels, transcript-summary actions, and imported-recording entry points.
- Fixed live translations occasionally disappearing when a later transcript-refinement event redraws the same segment.
- Prevented configured summary models from returning a tool call instead of summary text.

## Data compatibility

Existing meetings, recordings, downloaded models, configurations, summaries, and voice profiles remain in `~/brevia`.

## Installation notes

These are unsigned development builds. macOS may require **System Settings → Privacy & Security → Open Anyway**. Windows may show a Microsoft Defender SmartScreen prompt; choose **More info → Run anyway** only after verifying the download came from this release.
