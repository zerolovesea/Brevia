# Brevia v1.3.1

精简手机会议操作，完善等待反馈、版本显示及桌面设备连接界面。

Streamlines phone recording controls, waiting feedback, version details and desktop device management.

## 新增 / New

- 未上传的本地会议可从长按菜单选择上传到电脑。<br>Upload a local recording to a computer from its long-press menu.

## 改进 / Improvements

- 手机结束录音直接保存；右滑会议显示删除按钮，点击后直接删除手机副本。<br>Ending a recording saves directly. Swipe right to reveal Delete, then tap to remove the phone copy.
- 新建录音按电脑连接情况选择同步或本地保存，减少多余选项。<br>New recordings use the computer connection to choose syncing or local storage, with fewer setup options.
- 等待电脑输出期间持续显示三点动画，覆盖部分字幕、笔记和后续处理，并支持系统减少动态效果设置。<br>Three animated dots remain visible while waiting for desktop output, including partial transcripts, notes and follow-up processing, and respect reduced-motion settings.
- 桌面移除重复的手机录音标签及设备连接窗口中的会议操作区。<br>Removed duplicate phone-recording labels and the meeting controls in the desktop device connection dialog.
- 重整多语言使用文档，新增中英文开发指南和手机界面截图。<br>Reorganized multilingual user documentation and added English/Chinese developer guides and phone screenshots.

## 修复 / Fixes

- 等待动画显示时不再同时显示“暂无转写”；默认发言人名称按界面语言显示。<br>Waiting dots replace the empty transcript message; default speaker names follow the interface language.
- Android 检查更新显示当前版本、最新版本和构建号；退出设置页后不再继续发起版本检查请求。<br>Android update checks show installed and latest versions with build numbers, and no longer start a version-check request after leaving Settings.

## 使用说明 / Notes

- v1.3.1 是桌面版本号；手机端改进随配套移动构建分发。iOS 正式上架仍取决于 Apple 审核。<br>v1.3.1 is the desktop version; phone improvements ship through companion mobile builds. iOS public availability still depends on Apple review.
- 删除手机会议不再二次确认；未上传录音删除前请自行导出保留。<br>Deleting a phone meeting no longer asks for confirmation. Export unuploaded recordings first if you want to keep them.
