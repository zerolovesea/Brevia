# Brevia v1.1.7

## New

- Edit a meeting summary directly from the meeting details view.

## Improvements

- Reduced memory use and preparation time when refining long or imported recordings.
- Efficiency mode now completes imported-recording refinement faster by skipping speaker distinction; the app explains this trade-off before recording or importing.

## Fixes

- Fixed a Windows issue where the first load of audio-processing components could leave refinement preparation unresponsive for an extended time.
