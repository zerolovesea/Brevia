# Brevia v2.0.4

新增限时会议分享，改进长会议纪要，Windows 和 Linux 提供 CPU 与 CUDA 安装包。

Share expiring meeting snapshots, generate improved long meeting minutes, and choose CPU or CUDA installers for Windows and Linux.

## 新功能 / What’s new

- 桌面端可分享只读会议快照，选择有效期、设置密码，让读者按说话人查看原文和已保存的译文。<br>Share a read-only meeting snapshot with an expiry date and optional password. Readers can filter by speaker and view saved translations.

## 体验改进 / Improvements

- 长会议纪要可引用逐字稿原话，并复用已完成的分段结果。<br>Long meeting minutes can cite original transcript excerpts and reuse completed sections.

## 问题修复 / Fixes

- 修复 macOS 在蓝牙与内置麦克风之间切换后，双轨录音可能收不到麦克风音频的问题。<br>Fixed missing microphone audio in dual-track recordings after switching between Bluetooth and built-in microphones on macOS.
