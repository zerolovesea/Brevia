# Brevia v2.0.4

新增云端会议分享和 OpenCode Go 支持，完善手机与电脑协作，扩展跨平台语音推理，并改进长会议纪要。

Add cloud meeting sharing and OpenCode Go support, improve phone–computer collaboration, expand cross-platform speech inference, and improve long meeting minutes.

## 新功能 / What’s new

- 云端会议分享支持将会后纪要、原因图、逐字稿和已保存的译文生成只读网页，支持 3／7／15／30 天有效期、可选密码、说话人筛选和浏览次数。<br>Cloud meeting sharing lets you publish meeting minutes, the cause diagram, transcripts and saved translations as a read-only web page, with a 3-, 7-, 15- or 30-day expiry, optional password, speaker filters and view counts.
- 完善手机与电脑协作，可在手机端编辑电脑会议的共享笔记、查看转写、纪要与原因图，并同步纪要生成进度。完善断线草稿恢复与并发编辑冲突保护。<br>Phone–computer collaboration lets you edit shared notes for computer meetings from your phone, view transcripts, minutes and the cause diagram, and follow minutes-generation progress, with draft recovery after disconnection and protection against conflicting edits.
- 扩展跨平台语音推理，新增 Ubuntu 24.04 x86-64 桌面版，macOS 与 Linux 使用 MLX 转写，Windows 使用 ONNX。Windows 和 Linux 分别提供 CPU 与 NVIDIA CUDA 安装包。<br>Cross-platform speech inference adds an Ubuntu 24.04 x86-64 desktop app, with MLX transcription on macOS and Linux and ONNX on Windows. Windows and Linux each offer CPU and NVIDIA CUDA installers.
- 新增 OpenCode Go 在线模型服务商预设，可在 AI 设置中配置 API Key 和模型，用于会议纪要、智能笔记等功能。<br>Add an OpenCode Go online model provider preset. Configure an API key and model in AI settings for meeting minutes, smart notes and related features.

## 体验改进 / Improvements

- Windows 和 Linux 的应用内更新沿用已安装的 CPU／CUDA 版本，并在安装前校验签名。GitHub 不可达时可从 ModelScope 获取更新。<br>In-app updates on Windows and Linux preserve the installed CPU or CUDA variant and verify package signatures before installation, with ModelScope as a fallback when GitHub is unavailable.
- 长会议纪要可引用逐字稿原话，并复用已完成的分段结果。<br>Long meeting minutes can cite original transcript excerpts and reuse completed sections.

## 问题修复 / Fixes

- 修复 macOS 在蓝牙与内置麦克风之间切换后，双轨录音可能收不到麦克风音频的问题。<br>Fixed missing microphone audio in dual-track recordings after switching between Bluetooth and built-in microphones on macOS.
