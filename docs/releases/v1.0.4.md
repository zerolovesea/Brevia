# Brevia v1.0.4

## Fixes

- Made the onboarding screen-recording permission check reflect a successful native capture request immediately.
- Removed the stale permission-status polling that could make microphone authorization require repeated clicks.

## Build

- Added `npm run release:offline` for local-only DMG and Windows EXE builds without GitHub publishing or Apple notarization.

## Downloads

- **macOS (Apple Silicon):** `Brevia-1.0.4-arm64.dmg`, signed with Developer ID and notarized by Apple.
- **Windows x64:** `Brevia-1.0.4-x64-setup.exe`.
