# Brevia v1.0.23

## Highlights

- Improve live captions with a faster Chinese streaming model, more stable punctuation, speaker identification, and an optional power-saving mode.
- Run post-meeting refinement in an isolated process with cancellable progress, more resilient long-recording diarization, and improved speaker-profile matching.
- Simplify the model library by removing retired speech and voice-synthesis models, and improve PDF exports, task cards, and localized status messages.

## Fixes

- Preserve partial audio when recording stops and avoid repeated punctuation inference for unchanged live captions.
- Recover interrupted refinement safely and release native model resources when long-running work completes.
