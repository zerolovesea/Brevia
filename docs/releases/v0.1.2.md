# Brevia v0.1.2

Brevia v0.1.2 makes the desktop installers self-contained on Apple Silicon macOS and Windows x64.

## Highlights

- The DMG and EXE installers now bundle the Python runtime, NumPy, sherpa-onnx, and their native libraries.
- Brevia launches its bundled local worker automatically; users no longer need a separate Python installation to transcribe locally.
- Speech models remain on-demand downloads from the in-app model library, keeping the installer practical while preserving model licensing.

## Installation notes

These are unsigned development builds. macOS may require **System Settings → Privacy & Security → Open Anyway**. Windows may show a Microsoft Defender SmartScreen prompt; choose **More info → Run anyway** only after verifying the download came from this release.
