# Brevia v1.0.9

## Highlights

- **Built-in AI:** run bundled GGUF models locally for meeting summaries and text-to-speech, without configuring a remote API. Claude, OpenAI, OpenRouter, and custom OpenAI- or Anthropic-compatible services remain available.
- **Live controls:** change the meeting language, streaming/refinement models, translation target, and microphone or system-audio tracks while a meeting is in progress.
- **Better first-run setup and model library:** choose a quality or performance preference during onboarding, see clearer language, size, quality, and speed information in the library, and recover cleanly from cancelled downloads.

## Improvements

- Floating captions show when a translation is still pending and stay synchronized after refinements.
- Updated the supported ASR model defaults and streamlined the summary-provider configuration so each provider retains its own settings.
- Added an in-app GitHub button for quickly opening the Brevia repository.
