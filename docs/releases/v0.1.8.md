# Brevia v0.1.8

Brevia v0.1.8 fixes HTTPS model downloads in packaged desktop builds.

## Fixes

- Bundled a trusted CA certificate bundle with the Python Worker and configured it before any HTTPS request is made.
- Fixed macOS and Windows installers failing model downloads with `CERTIFICATE_VERIFY_FAILED` when the bundled Python runtime could not locate a system certificate store.

## Data compatibility

Existing meetings, recordings, model downloads, configurations, summaries, and voice profiles remain in the same local Brevia data directory.

## Installation notes

These are unsigned development builds. macOS may require **System Settings → Privacy & Security → Open Anyway**. Windows may show a Microsoft Defender SmartScreen prompt; choose **More info → Run anyway** only after verifying the download came from this release.
