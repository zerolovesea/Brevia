# Brevia v1.0.16

## Fixes

- Fixed the release build so the bundled Python worker can be packaged on macOS and Windows.

## Highlights

- Added workspaces for organizing meetings, with workspace switching, assignment, and localized labels.
- The live meeting panel can now collapse into a right-side drawer.
- Large meetings now open reliably without exceeding the worker response limit.
- Removed source separation and the dual-track recording view from the product interface.

## Downloads

- **macOS (Apple Silicon):** `Brevia-1.0.16-arm64.dmg`.
- **Windows x64:** `Brevia-1.0.16-x64-setup.exe`.
