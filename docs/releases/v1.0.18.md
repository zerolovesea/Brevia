# Brevia v1.0.18

## Fixes

- Fixed meeting-note generation when empty refinement results obscured the live transcript.
- Reuse a cleaned transcript when regenerating notes, including after a temporary generation failure; re-clean only after the transcript changes.
- Prevent built-in Qwen models from exposing their reasoning output in meeting notes.
- Reset the pause control when starting a new recording, so the displayed state matches active recording.
- Stop automatic post-meeting refinement; refinement remains available on demand.
