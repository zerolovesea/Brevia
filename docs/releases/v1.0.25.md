# Brevia v1.0.25

## Highlights

- Rework live captions around single-stage streaming with in-place refinement: sentences now split at semantic boundaries (sentence-final or punctuation) instead of a fixed time limit, so long speech is no longer cut mid-word and subtitles stay in place.
- Speed up meeting startup by loading speech models in the background and buffering early audio, so recording begins almost immediately without losing the opening seconds.
- Improve post-meeting refinement: merge same-speaker speech into sentence-aligned segments capped at ~30s, trim window-overlap duplication, and split at real sentence boundaries instead of mid-sentence.

## Fixes

- Stop inter-sentence repetition in refined transcripts caused by decoding the same overlap audio twice.
- Align caption timestamps with the audio when a sentence is split at a pause, removing overlapping time ranges.
- Delete a meeting immediately by cancelling any running background task instead of blocking with an error.
- Match enrolled voiceprints more reliably with a dedicated threshold, separate from speaker clustering.
- Kill the whole worker process group on shutdown so ffmpeg and the LLM sidecar are not left orphaned.

## Improvements

- Add a select-all control to the meeting library for batch actions.
- Reduce live-caption lag by running punctuation and refinement on separate workers.
- Let the installer stop background transcription before updating.
