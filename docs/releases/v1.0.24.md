# Brevia v1.0.24

## Improvements

- Refine-menu model choices now show concise names and capability tags, with a compact, left-aligned dropdown.
- Localize refinement-model tags for every supported app language.
- Use FunASR Nano by default for Chinese post-meeting refinement, and update the Nemotron streaming runtime.

## Reliability

- Load native speech models sequentially to avoid initialization contention, and clear stale recording state when a worker cannot recover.
- Remove retired streaming and diarization models from the model library.
