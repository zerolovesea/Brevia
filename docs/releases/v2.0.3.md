# Brevia v2.0.3

修复 macOS 识别模型加载失败，模型库按平台展示，并在录制来源下标明适用场景。

Fix speech model loading on macOS, show models for each platform, and add recording-source guidance.

## 新功能 / What’s new

- 新建会议时，在麦克风、系统音频、双轨和手机麦克风下方查看适用场景，便于选择网课、播客、线上或线下会议的录制来源。<br>See suggested uses below each recording source to choose how to record classes, podcasts, online meetings or in-person conversations.

## 体验改进 / Improvements

- macOS 的识别模型库仅提供 MLX，Windows 提供 ONNX。模型统一显示原名称，保留已有录音、逐字稿和模型文件。<br>The speech model library offers MLX on macOS and ONNX on Windows, using original model names. Existing recordings, transcripts and model files are preserved.

## 问题修复 / Fixes

- 修复 macOS 安装包缺少 Metal 计算资源，导致部分模型无法生成实时字幕或会后逐字稿的问题。<br>Fixed missing Metal resources in the macOS app package that prevented some models from producing live captions or post-meeting transcripts.
- 从历史会议快速录音、恢复手机录音或重新精修时，优先保留同家族、同容量的本机模型，避免把原来的 Qwen 选择改成默认模型。<br>Quick recording, phone recording recovery and transcript refinement preserve the matching local model family and size instead of replacing a previous Qwen choice with the default model.
- 快捷开会重新校验模型的语言和识别能力，旧配置中的退役模型不再被重新启用。<br>Quick recording validates the model’s language and transcription support. Retired models saved in older configurations are no longer reactivated.
