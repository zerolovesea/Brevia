# Brevia v0.1.3

Brevia v0.1.3 adds the Brevia app icon to both desktop installers.

## Highlights

- The Apple Silicon DMG installs Brevia with its native macOS icon.
- The Windows x64 EXE installer and installed app use the matching Brevia icon.

## Installation notes

These are unsigned development builds. macOS may require **System Settings → Privacy & Security → Open Anyway**. Windows may show a Microsoft Defender SmartScreen prompt; choose **More info → Run anyway** only after verifying the download came from this release.
