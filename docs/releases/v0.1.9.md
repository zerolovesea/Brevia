# Brevia v0.1.9

Brevia v0.1.9 makes Chinese meeting defaults more reliable and keeps all local app data in one clear location.

## Fixes

- Fixed the model-download pause race: clicking Pause after a completed or failed download no longer shows “Model is not downloading”.
- Chinese meetings now default to **Streaming Zipformer Chinese XLarge** for live transcription and **FunASR Nano int8** for post-meeting refinement.
- Warnings and errors from the app, Worker, and failed downloads are appended to `~/brevia/logs/brevia.log`.

## Data location

- Models, meetings, recordings, and logs now use `~/brevia`.
- On first launch, existing data is moved from the previous Brevia application-data directory when the new database does not yet exist.

## Installation notes

These are unsigned development builds. macOS may require **System Settings → Privacy & Security → Open Anyway**. Windows may show a Microsoft Defender SmartScreen prompt; choose **More info → Run anyway** only after verifying the download came from this release.
