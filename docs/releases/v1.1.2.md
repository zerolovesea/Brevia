# Brevia v1.1.2

## Improvements

- Starting a meeting now immediately queues and shows required model downloads; recording starts automatically once they are ready.
- Made the settings overview more compact so its options and update action are visible together, and widened the fixed sidebar to keep the new-workspace action on one line.
- The Windows installer now uses the appropriate elevated installation flow when installing outside the default user location.
- Chinese website downloads now use the ModelScope mirror, while international downloads continue to use GitHub Releases.
- Application updates and release artifacts are mirrored to ModelScope as part of each release.

## Localization

- Completed workspace, audio, recording-permission, and model-selection labels across all supported interface languages.
