# Brevia v0.1.10

Brevia v0.1.10 makes the meeting library appear immediately and significantly reduces repeat startup time in packaged desktop builds.

## Improvements

- Cached the last verified meeting list in the frontend and refreshes it from the local database after startup.
- Changed the bundled Python Worker from a self-extracting single file to a directory-based runtime, avoiding repeated extraction on every launch.
- Extended the startup splash slightly for a smoother transition into the meeting library.

## Data compatibility

Existing meetings, recordings, model downloads, configurations, summaries, and voice profiles remain in `~/brevia`.

## Installation notes

This is an unsigned development build. macOS may require **System Settings → Privacy & Security → Open Anyway**.
