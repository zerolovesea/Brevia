# Brevia v1.4.3

修复 Windows 会后精修启动卡死，完善后台进程收尾，并修复设置、设备连接与安装更新相关问题。

Fixed Windows refinement startup freezes, strengthened background process cleanup, and resolved settings, device connection and update issues.

## 改进 / Improvements

- 切换设置页与保存 AI 配置时保留当前页面，完善会议纪要生成中的反馈与动效。<br>Keep the current settings page when navigating or saving AI configuration, with clearer feedback and animation during meeting summary generation.
- 统一分析进程的关闭与异常清理，防止后台进程残留及清理失败后继续加载模型。<br>Unified analysis process shutdown and failure cleanup to prevent orphaned processes and further model loading after cleanup fails.

## 修复 / Fixes

- 修复 Windows 精修分析子进程因继承命令输入管道而卡在启动阶段、进度长时间停在 15% 的问题。<br>Fixed Windows analysis subprocesses stalling during startup because they inherited the command input pipe, leaving refinement at 15%.
- 修复精修模型加载、字幕整理或保存失败后，界面仍停留在精修进行态的问题；严格执行分析启动及推理超时。<br>Refinement now leaves the in-progress state when model loading, transcript assembly or saving fails. Analysis startup and inference deadlines are enforced.
- Windows 安装器不再在打开或取消时强制终止所有同名后台进程；应用内更新会在下载前和安装前检查录音及后台任务，避免中断会议。<br>Opening or cancelling the Windows installer no longer forcibly stops every background process with the same name. In-app updates check recording and background tasks before downloading and before installation.
- 修复 Windows 默认窗口下英文设备连接页多余滚动，并统一设备服务开关和配对码复制按钮的八语言可访问标签。<br>Removed unnecessary scrolling on the English device connection page at the default Windows window size, and localized accessibility labels for the service switch and pairing-code copy button in all eight languages.
- 修复高级设置恢复默认后仍显示“已保存”的问题，并清理未使用的引导样式。<br>Fixed advanced settings reporting “Saved” after restoring defaults, and removed unused onboarding styles.

## 使用说明 / Notes

- v1.4.3 为桌面版本，提供 macOS Apple Silicon 与 Windows x64 安装包；手机客户端不随本次桌面发布自动升级。<br>v1.4.3 is a desktop release for Apple Silicon macOS and Windows x64. Mobile clients are not automatically upgraded by this desktop release.
