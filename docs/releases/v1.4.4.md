# Brevia v1.4.4

新增可预览、可撤销的批量文字纠错，改善长会话与手机录音稳定性，并统一应用图标和官网导航。

Add previewable, undoable bulk text corrections, improve long-session and mobile recording stability, and unify app branding and website navigation.

## 新增 / New

- 逐字稿、笔记和会议纪要支持批量查找替换：先预览、逐项选择，再统一保存，并可撤销最近一次替换。<br>Find and replace text across transcripts, notes and meeting summaries: preview matches, select individual occurrences, save them together and undo the latest replacement.
- 录音中可将纠错规则应用到本场后续字幕，集中修正人名与术语；规则可查看、停用和撤销。<br>Apply correction rules to subsequent captions in the current recording to keep names and terms consistent, with controls to inspect, disable and undo rules.

## 改进 / Improvements

- 精简会议读取和手机会议快照缓存，减少长会话与大型会议库的重复加载和内存占用。<br>Reduce repeated loading and memory use in long sessions and large meeting libraries with leaner meeting reads and mobile snapshot caching.
- 统一桌面、手机、开屏与安装图标的品牌图形，固定字形并适配深色模式。<br>Unify branding across desktop, mobile, startup screens and app icons, with fixed letterforms and dark-mode support.
- 官网使用专属手绘 Logo，导航新增 GitHub 入口与自动获取的星数，并改善手机端图标布局。<br>Add a bespoke hand-drawn website logo and a GitHub navigation link with an automatically fetched star count, with a compact mobile header layout.
- 完善键盘输入、八语言提示与界面状态保持，并清理重复逻辑和未使用样式。<br>Improve keyboard input, messages in all eight interface languages and UI state preservation, and remove duplicate logic and unused styles.

## 修复 / Fixes

- 修复切换会议后，实时翻译可能读取或更新错误会议的问题。<br>Fix live translation reading or updating the wrong meeting after navigation.
- 修复替换与撤销后，纪要待更新状态丢失，以及重新精修后译文状态仍引用旧分段的问题。<br>Preserve summary update warnings after replacement or undo, and keep translation state aligned with the current segments after refinement.
- 已删除或正在精修的会议会拒绝文字修改；批量撤销保留各范围的独立备份，避免覆盖后续人工编辑。<br>Reject text edits to deleted meetings or meetings being refined, and keep separate undo backups for each text scope to protect subsequent manual edits.
- 手机录音写入积压时显示明确中断提示并保留已落盘音频，避免缓冲持续增长。<br>Show a clear interruption when mobile recording writes fall behind, preserving audio already saved to disk and preventing unbounded buffering.

## 使用说明 / Notes

- v1.4.4 提供 macOS Apple Silicon 与 Windows x64 安装包；手机端通过独立更新渠道升级，协作录音仍需手机与电脑处于同一局域网。<br>v1.4.4 provides installers for Apple Silicon macOS and Windows x64. Mobile clients update through their own distribution channels, and collaborative recording still requires the phone and computer to share a local network.
