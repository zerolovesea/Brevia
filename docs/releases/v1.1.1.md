# Brevia v1.1.1

## Improvements

- Improved built-in meeting summaries: local GGUF models now use their chat template, avoiding reasoning-token output that could truncate the final notes. Summary output capacity has also been increased for complete, focused notes.
- Refined AI Assist Notes in the live-meeting toolbar with a quieter request action, consistent teal signals, stable spacing, and dark-theme support.
- Fixed ordered and unordered list rendering in rich-text notes.
- Made summary regeneration use the same generation flow as the primary summary action.
- Kept the software-update notice clear of the sidebar divider.

## Documentation

- Updated every README language with AI Assist Notes, localized demo GIFs, and current application screenshots for live captions, speaker identification, and model management.

## Notes

- AI Assist remains optional. With a remote provider, only transcript text and current note context are sent; audio stays on your device.
