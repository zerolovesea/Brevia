# Brevia v1.1.3

## Improvements

- Simplified the meeting setup flow to use the stable FunASR Nano refinement model by default, while keeping per-meeting model selection available when refining a finished recording.
- Improved offline refinement around overlapping decoding windows: repeated openings, truncated restarts, decimal values, and corrected Chinese number fragments now produce a cleaner transcript.
- Ignore late audio frames while the system is stopping a meeting for sleep, preventing stale worker errors.
- Reduced recording I/O by reusing WAV handles and checkpointing the recording manifest; recovery now derives duration from the recorded WAV data after an unexpected stop.
- Isolated AI-assist sidecar cancellation so switching or stopping one task does not unnecessarily interrupt other inference work.
- Website download buttons now link directly to the current release and are updated automatically after publishing.

## Fixes

- Prevented alphanumeric identifiers such as `A1` and `A2` from being mistaken for numeric ASR corrections.
- Updated README demos and product screenshots to show only the application interface without surrounding white canvas.
- Disabled meeting-note generation while a meeting is recording, avoiding concurrent processing conflicts.

## Localization

- Localized AI-assist prompts and meeting-state labels across all supported interface languages.
- Kept the refreshed meeting setup and refinement controls consistent across all supported interface languages.
