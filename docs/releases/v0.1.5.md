# Brevia v0.1.5

Windows hotfix.

- Read all local JSON resources and user settings as UTF-8, so Chinese content no longer fails under the Windows GBK default encoding.
- Explicitly configure the bundled worker's UTF-8 environment.
- Make the GIF launch screen reliably visible on Windows.
- Grant the local app's microphone and screen-capture media permissions through Electron before capture starts.

Existing meetings, recordings, model downloads, configurations, and voice profiles remain in the same local data directory.
