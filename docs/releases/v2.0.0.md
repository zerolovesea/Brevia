# Brevia v2.0.0

桌面版改用系统原生窗口。实时字幕可标注说话人，回看会议时可从纪要定位到原始发言，本机 Agent 也可调用转写和翻译。

The desktop app now uses native windows. Live captions can identify speakers, meeting reviews link back to the original speech, and local agents can transcribe and translate files.

## 新增 / New

- 从会议纪要和原因图跳转到对应的逐字稿与录音，核对结论的上下文。<br>Follow a meeting summary or cause diagram back to the transcript and recording to check a conclusion in context.
- 在设置中复制 Agent 接入引导语，通过本机 CLI 或 MCP 查询会议、控制录音、转写文件和翻译字幕。<br>Copy the Agent setup instructions from Settings to query meetings, control recordings, transcribe files and translate subtitles through the local CLI or MCP.
- 安装声纹模型后，实时字幕可根据原始语音片段识别说话人。证据不足时保留未知身份。<br>With the speaker embedding model installed, live captions can identify speakers from the original speech. Uncertain matches stay unlabeled.

## 改进 / Improvements

- 桌面主窗口默认按 90% 显示，内容区为 1152 × 720。会议纪要、逐字稿和侧栏同比缩放，小屏幕会继续适配可用空间。<br>The desktop window opens at 90% scale with a 1152 × 720 content area. Meeting notes, transcripts and the sidebar scale together, and the window fits smaller screens.
- 手机离线录音完整传至电脑后即可离开手机应用，电脑会继续导入，重启后也可恢复处理。<br>Once an offline phone recording has transferred in full, you can leave the mobile app. The desktop continues importing and can resume after a restart.
- macOS 使用 WebKit，Windows 使用 WebView2。两端均随包提供推理引擎，转写模型仍按需下载。<br>The desktop app uses WebKit on macOS and WebView2 on Windows. Both installers include inference engines, and transcription models download on demand.

## 修复 / Fixes

- 取消手机信任后，排队中的请求会在执行前重新校验权限；手机保存会议快照时会按提交顺序写入。<br>Queued phone requests recheck access after trust is revoked. The mobile app now saves meeting snapshots in submission order.
- 修复 Windows 双轨录音停止时末批音频可能遗漏的问题。<br>Preserve the final audio frames when stopping a dual-track recording on Windows.
- 已结束会议的录音时长按保存的音频计算，避免把暂停时间计入录音。<br>Calculate the duration of a completed recording from the saved audio so time spent paused is excluded.

## 使用说明 / Notes

- 升级后，已信任的手机可访问电脑会议库，包括旧版中关闭过会议库访问的设备。可在「设置 → 设备连接」查看设备并取消信任。<br>After upgrading, trusted phones can access the desktop meeting library, including devices whose library access was turned off in the previous version. Review devices and revoke trust in Settings → Device connections.
- v2.0.0 是桌面端大版本更新。从 v1.4.5 升级时，请先保存录音，等待后台任务结束，再在应用内点击「检查更新」并安装。升级后会沿用已有会议、录音和已下载的模型。macOS 需要 Apple Silicon 和 macOS 14 或以上，Windows 需要 Windows 10/11 x64 和支持 AVX2 的处理器。<br>v2.0.0 is a major desktop update. In v1.4.5, save your recording, wait for background tasks to finish, then select Check for updates and install the update from within Brevia. Your meetings, recordings and downloaded models carry over. macOS requires Apple Silicon and macOS 14 or later. Windows requires Windows 10/11 x64 and a processor with AVX2.
