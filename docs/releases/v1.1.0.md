# Brevia v1.1.0

## Highlights

- Added AI Assist Notes for live meetings. It can surface decisions, action items, key numbers, risks, questions, and topic changes while you record.
- Added three assistance levels: request-only, key-point notifications, and automatic note organization. AI Assist reuses your existing meeting-summary model configuration.
- Added a rich-text and Markdown notes editor with headings, lists, quotes, links, images, tables, inline code, todos, and highlights.
- Added quick actions to insert a live caption or timestamp into your notes, plus transcript context-menu actions for the same workflow.

## Improvements

- Improved live-meeting layout so notes and captions can be emphasized independently.
- Added localized AI Assist UI and onboarding across all supported app languages.
- Improved summary cancellation and prevented late summary tasks from writing to deleted meetings.
- Improved local LLM sidecar cancellation and CPU testing controls for realtime AI tasks.

## Notes

- AI Assist is optional. With a remote provider, only transcript text and the current note context are sent to that provider; audio remains on your device.
