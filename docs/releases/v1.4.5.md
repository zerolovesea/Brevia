# Brevia v1.4.5

新增快速录音、菜单栏／托盘与悬浮录音胶囊，完善后台录音、保存和八语言提示。

Add quick recording, menu bar and tray controls, and a floating recording capsule, with more reliable background recording, saving and messages in all eight languages.

## 新增 / New

- 首页、侧栏与菜单栏支持快速录音，沿用最近会议的语言、模型和工作区，以麦克风与系统音频开始采集；缺模型时进入准备页确认。<br>Start quick recordings from the home page, sidebar or menu bar using the latest meeting’s language, models and workspace, with microphone and system audio capture. Missing models open the preparation page for confirmation.
- 新增悬浮录音胶囊：主窗口最小化或隐藏时控制暂停、结束与保存，悬停查看实时字幕、本场笔记并采纳 AI 建议。<br>Use the floating recording capsule to pause, end and save while the main window is minimized or hidden. Hover to review live captions and meeting notes, and accept AI suggestions.
- 新增菜单栏／托盘入口与后台窗口设置，可选择关闭主窗口后继续录音；真正退出时确认并等待录音保存。<br>Add menu bar and tray controls with background window preferences. Optionally keep recording when the main window closes; quitting asks for confirmation and waits for the recording to be saved.

## 改进 / Improvements

- 本地纪要模型尚未安装时展示等待状态，安装完成后自动继续；统一会议结束后的收尾和任务恢复，避免重复处理。<br>Show a waiting state when a local summary model is missing and continue after installation. Use one completion flow to finalize meetings and resume queued tasks without duplicate handling.
- 主界面、菜单栏、录音胶囊与悬浮字幕共用翻译查询，补齐八种语言的桌面错误提示，清理废弃文案和无效样式。<br>Share translation lookup across the main interface, menu bar, recording capsule and floating captions, with desktop error messages in all eight languages and obsolete copy and styles removed.

## 修复 / Fixes

- 修复快速录音与普通录音同时启动时，可能停止另一场采集或遗失采集资源的问题。<br>Prevent overlapping quick and regular recording starts from stopping another capture or losing ownership of capture resources.
- 修复手机停录请求或笔记保存失败后，电脑错误显示已暂停并停止计时的问题。<br>Keep the real recording state and timer when a phone stop request or note save fails, instead of incorrectly showing the recording as paused.
- 修复胶囊采纳 AI 建议时重复保存、保存结果与建议状态不一致的问题；失败后仍可重试且不重复追加笔记。<br>Save accepted AI suggestions once and keep capsule acknowledgements aligned with the save result. Failed saves remain retryable without appending duplicate notes.
- 修复清空笔记后立即结束录音时，空笔记未能保存的问题；会议列表刷新失败不再影响停录结果。<br>Save empty notes when a recording ends immediately after the notes are cleared, and keep meeting-list refresh failures from changing the recording’s save result.
- 修复安装版菜单栏／托盘图标加载路径，并在再次启动应用时恢复已隐藏的主窗口。<br>Fix menu bar and tray icon loading in packaged apps, and restore the hidden main window when the application is launched again.

## 使用说明 / Notes

- v1.4.5 提供 macOS Apple Silicon 与 Windows x64 安装包；手机端通过独立更新渠道升级，协作录音仍需手机与电脑处于同一局域网。<br>v1.4.5 provides installers for Apple Silicon macOS and Windows x64. Mobile clients update through their own distribution channels, and collaborative recording still requires the phone and computer to share a local network.
