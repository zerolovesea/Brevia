# Brevia v1.0.1

## Fixes

- Restored the native macOS screen-selection flow when granting screen and system-audio recording access.
- Added recovery actions for microphone and screen-recording permissions that open the matching macOS Privacy settings.
- Improved first-run permission guidance after a prior permission denial.

## Downloads

- **macOS (Apple Silicon):** `Brevia-1.0.1-arm64.dmg`, signed with Developer ID and notarized by Apple.
- **Windows x64:** `Brevia-1.0.1-x64-setup.exe`.
