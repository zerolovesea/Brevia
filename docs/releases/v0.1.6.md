# Brevia v0.1.6

Brevia v0.1.6 hardens the local meeting workflow and refines the desktop experience.

## Highlights

- Made meeting shutdown resilient: an audio-flush failure no longer leaves a recording stuck as an active session.
- Prevented refinement from processing the meeting currently being recorded, and strengthened validation of advanced local settings.
- Tightened Electron local-file access checks for audio playback and “show in folder” actions, including symbolic-link resolution.
- Improved startup reliability so the splash is rendered before the main window is shown, and kept it visible slightly longer.
- Improved the responsive refinement-model menu so long model names use the available menu width and wrap instead of being clipped.
- Reorganized the local worker and storage code into focused modules, with regression coverage for the lifecycle and validation paths.

## Data compatibility

Existing meetings, recordings, model downloads, configurations, and voice profiles remain in the same local Brevia data directory.

## Installation notes

These are unsigned development builds. macOS may require **System Settings → Privacy & Security → Open Anyway**. Windows may show a Microsoft Defender SmartScreen prompt; choose **More info → Run anyway** only after verifying the download came from this release.
