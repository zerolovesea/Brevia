# Brevia v0.1.4

Brevia v0.1.4 improves the first-run offline transcription setup, task feedback, playback continuity, and multilingual consistency.

## Highlights

- Redesigned offline-transcription onboarding: meeting languages and offline capabilities each show their own fixed-height model download list and storage estimate.
- Custom model downloads now open from onboarding, support multi-selection, and continue in the main app through compact download cards.
- Unified task cards for downloads, refinement, source separation, summaries, and playback, including stacking, minimize/restore, pause/resume, close controls, and progress feedback.
- Playback continues while navigating between views and while refinement completes; the compact player supports scrubbing and displays progressively revealed current captions.
- Added model-download pause and cancellation, plus task pause/resume controls for refinement, source separation, and summary generation.
- Completed translations and locale switching across onboarding, model library, storage cleanup, speaker recognition, and summary-model settings.
- Improved responsive layout, scrolling behavior, checkbox rendering, and Electron window interaction during onboarding.

## Data compatibility

This release keeps existing meetings, recordings, model downloads, summary configurations, and voice profiles in the local Brevia data directory.

## Installation notes

These are unsigned development builds. macOS may require **System Settings → Privacy & Security → Open Anyway**. Windows may show a Microsoft Defender SmartScreen prompt; choose **More info → Run anyway** only after verifying the download came from this release.
