# Brevia v0.1.0

Brevia's first macOS development release is available for Apple Silicon Macs.

## Highlights

- Separate microphone and system-audio transcription streams, merged by timestamps.
- Real-time captions with a slower revision pass that can replace the latest subtitle.
- Enrollment-based speaker profiles for stable naming and diarization.
- A new animated startup experience.
- Local-first recordings, transcripts, exports, and model management.

## Installation note

This is an unsigned, non-notarized development build. If macOS blocks Brevia, use **System Settings → Privacy & Security → Open Anyway**, or run:

```bash
xattr -dr com.apple.quarantine "/Applications/Brevia.app"
```

The DMG does not yet include a portable Python runtime or speech-model dependencies. Install the Python requirements from a source checkout before using local transcription.
