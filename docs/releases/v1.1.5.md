# Brevia v1.1.5

## Improvements

- Improved long-running live captions with semantic boundaries that retain enough audio context for the next segment.
- Use FunASR Nano by default for Chinese and English refinement, and Qwen3-ASR for other supported meeting languages.
- Rebuilt the bundled frontend styles from the Tailwind source.

## Fixes

- Preserve the current live-caption partial when a forced ASR endpoint returns an empty final result.
- Keep the selected refinement model when refining or re-refining a meeting.
- Allow only one meeting-summary task at a time, both in the interface and in the worker.
- Keep a collapsed meeting-detail header collapsed during background detail refreshes.
