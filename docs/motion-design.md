## 七个核心原则

用户提供的列表包含六项具名原则；第七项补为“可中断与可控”，落实不牺牲操作效率的要求。

| 原则                            | 用户需要理解的事情         | 在 Brevia 中的表达                                                    | 不采用                                           |
| ------------------------------- | -------------------------- | --------------------------------------------------------------------- | ------------------------------------------------ |
| Feedback · 反馈                 | 操作已被接收               | 按下缩小按钮内容；请求开始当帧显示忙碌状态                            | 等动画结束才发请求；无意义的整卡跳动             |
| Continuity · 连续性             | 变化前后是同一份内容       | 会议行进入同名详情，返回恢复原行、筛选与滚动；任务在后台保持          | 切页重新播放全部列表入场；重建编辑器导致光标丢失 |
| Hierarchy · 层级                | 当前需要处理哪一层         | 面板位于原内容之上，遮罩让背景降级；菜单锚定触发器                    | 所有浮层都从屏幕底部出现；多层遮罩叠黑           |
| Orientation · 方向感            | 正在深入、返回，还是换分类 | 父子横向推进 / 逆向返回；同级正文直接接手、选中底过渡；页内移动指示线 | 同级分类左右大幅滑动；返回仍从同一方向进入       |
| Attention · 注意力              | 哪个变化值得看             | 新字幕或已采纳笔记短暂底色强调一次；完成状态留在任务区                | 持续闪烁红点、反复抖动、自动弹出完成窗口         |
| State Change · 状态变化         | 当前处于什么状态           | 播放 / 暂停图标在同一位置交接；保存中 → 成功 / 失败                   | 处理中预先显示勾号；随机进度；靠颜色单独传意     |
| Interruptibility · 可中断与可控 | 界面仍受用户控制           | 连续操作不排队；手势可取消；减少动态效果；隐藏暂停                    | 锁住页面等待动画；自动滚动夺取阅读位置           |

判断方法：移除动画后，是否更难确认操作、理解空间关系或辨认变化位置？若没有，应删去。克制的品牌动画只保留在现有首启与营销演示，不扩散到搜索、输入、列表浏览和设置。

## 时间、距离与节奏

所有持续时间都是目标上限；业务请求立即开始，事件结果立即生效。真实响应很快时允许跳过短暂 loading 外观，不能刻意等待“演完整”。请求较慢时保留状态直到完成，不拉伸一次性转场。

| Token             | 值                      | 用途                                          |
| ----------------- | ----------------------- | --------------------------------------------- |
| `motion.press`    | 80ms                    | 按下确认                                      |
| `motion.feedback` | 120ms                   | Hover、图标交接、真实进度插值上限             |
| `motion.state`    | 180ms                   | 标签底、模式选择、局部状态变化、按压释放      |
| `motion.surface`  | 220ms                   | 桌面弹窗进入；手机普通路由基准沿用现有 220ms  |
| `motion.spatial`  | 280ms                   | 桌面父子内容接手、手机底部弹层                |
| `motion.sibling`  | 正文即时 / 指示180ms    | 同级不重新淡入整页，保留选中反馈              |
| `motion.exit`     | 140ms                   | 桌面弹窗退出；菜单 100ms，父子 / 手机层 180ms |
| `motion.reduced`  | 0 / 80ms                | 位置直接就位；需要确认层级时仅 80ms 淡化      |
| `motion.emphasis` | 240ms 保留 + 800ms 退去 | 新增内容单次强调，总长不超过 1120ms           |

小元素快于大区域；退出快于进入；搜索、标签、切换开关等高频动作优先 80–180ms。常规 UI 不超过 280ms；首次工作台入场例外为520ms，交互立即可用。无逐行错峰入场。若极少量列表需要首次解释顺序，总错峰不超过 60ms，首项当帧可操作；本稿不使用列表错峰。

| 场景                | 距离 / 幅度                                | 进入                   | 退出                                      |
| ------------------- | ------------------------------------------ | ---------------------- | ----------------------------------------- |
| 按钮内容            | 桌面 .98；手机沿用 .96；不缩触控边界       | 按下 80ms              | 释放 180ms；手机已统一80ms按下、180ms释放 |
| 桌面父子正文        | 进入 +24px → 0；旧内容最多 -8px            | 280ms                  | 180ms，反向                               |
| 同级正文 / 内容标签 | 0px；只移动选中指示                        | 正文即时 / 指示180ms   | 桌面即时；手机旧层交接80–120ms            |
| 桌面弹窗            | +12px、scale .98 → 1；不改变定位锚点       | 面板 220ms，遮罩 160ms | 面板 140ms，遮罩 100ms                    |
| 锚定菜单            | 6px，朝可用方向；transform-origin 为触发边 | 160ms                  | 100ms                                     |
| 手机底部弹层        | 面板自身高度 → 0，保持底边关系             | 280ms                  | 180ms，跟手返回以手势为准                 |
| 任务卡              | 不做宽高反复伸缩；新卡可 6px + 透明度      | 160ms                  | 120ms；列表稳定锚点                       |
| 新字幕 / 保存状态   | 0px，不挤动既有文字                        | 120–180ms              | 文字状态持续，临时高亮自行退去            |
| 主题                | 0px，颜色或小区域交叉淡化                  | 120ms                  | 同步，不逐个组件延迟                      |

## 四类缓动

| Token          | Web                                           | Flutter 对应方式                                               | 使用                                       |
| -------------- | --------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------ |
| `ease.out`     | `cubic-bezier(.16, 1, .3, 1)`                 | `Cubic(.16, 1, .3, 1)`                                         | 页面、弹窗和菜单到达                       |
| `ease.in`      | `cubic-bezier(.4, 0, 1, 1)`                   | `Cubic(.4, 0, 1, 1)`                                           | 面板和菜单退出                             |
| `ease.inOut`   | `cubic-bezier(.4, 0, .2, 1)`                  | `Cubic(.4, 0, .2, 1)`                                          | 指示线、开关、局部状态交接                 |
| `spring.press` | 关键帧 `1 → .98 → 1.004 → 1`，总 260ms 含按下 | 控件内容使用有限 Spring / 现有 AnimatedScale；导航继续平台物理 | 仅低频明确按压释放；正文、弹窗与菜单不回弹 |

Spring 是有界的弹性响应，不是 `ease-out` 的别名。Web 使用确定性关键帧实现 80ms 按下 + 180ms 释放的响应轮廓，并非声称浏览器关键帧等于物理弹簧。若生产端实施物理 Spring，初值取 mass 1、stiffness 500、damping 32，以无明显二次振荡、约 180ms 释放收敛为验收依据；真机校准前不把物理参数视为跨端等价常数。减少动态效果时移除弹性和缩放。

## 导航与连续性

### 同级：会议库 / 最近删除，设置分类，工作区筛选

侧栏、标题锚点和可用任务保持稳定，旧正文与新正文当帧交接，选中底 / 指示线180ms过渡；不让整页从透明度0重新出现。设置始终保持 224px 主侧栏、200px 设置导航。工作区切换不清空任务、不重置下载和录音、不改变任务区滚动位置。

### 父子：会议库 → 详情、会议入口 → 准备页、手机列表 → 录音准备 / 回看

桌面用短距离横移表示深入，返回沿原方向逆向退出；保持会议信息身份一致，不把整行拉伸成一张假卡片。父列表保留排序、筛选、滚动和触发项。返回后焦点落回原行；如果该行已被真实删除，转到邻近可用项或列表标题。

进入实时录音属于业务状态变化，不能仅靠导航动画承诺“已开始”。必须等待实际录音状态；权限拒绝留在可恢复位置。录音中返回只隐藏前台内容，不改变既有后台录音语义。

手机保留 iOS 交互式侧滑返回和 Android 系统返回。系统过渡比固定毫秒优先；中途取消手势应回到完整前页，不重复提交或重建录音。减少动态效果不取消返回手势。

### 页内：笔记 / 逐字稿 / 纪要、编辑模式、语言与模型筛选

详情标签即时选中，桌面正文统一从下方6px接手，180ms Ease Out，透明度始终为1；手机正文保留旧层交叉淡化最长120ms，切换期间不左右飞入。笔记与 Markdown 源码沿用同一草稿；不在动效层重新创建编辑器。不动画输入框高度来掩盖真实布局问题。桌面笔记、逐字稿、纪要共用单栏阅读区；切换不改变列宽、页头、导出和播放器位置。不挤压正在编辑的正文。

页标题、播放器、当前时间不随内容标签重新入场。搜索结果按真实输入更新，不引入额外动画防抖，也不为每个结果添加排队延迟。

## 按钮与组件状态

| 状态     | 视觉                                            | 时间 / 曲线                              | 行为边界                                                      |
| -------- | ----------------------------------------------- | ---------------------------------------- | ------------------------------------------------------------- |
| Default  | 既有背景、文字、图标                            | 静态                                     | 保留标准触控尺寸和读屏名称                                    |
| Hover    | 中性底色或边界变化，不抬高整张卡                | 120ms Ease Out                           | 只用于有悬停能力的指针；不把 Hover 设为触摸必经状态           |
| Pressed  | 桌面内容 .98、手机 .96；可同时轻微加深背景      | 80ms，释放 180ms / 原生既有值            | 仅内容变化，点击区域与键盘定位不缩小；取消按下恢复            |
| Loading  | 图标与“正在保存 / 正在导出”等文字；固定最小宽度 | 120ms 交接；spinner 仅在真实请求期间循环 | 使用 `aria-busy` / 原生语义，防重复提交；不等动画完成才发请求 |
| Success  | 勾号 + 明确完成文字，阅读保存状态可用成功点     | 120ms Ease Out                           | 由真实响应触发；持久状态不能只依赖短 Toast                    |
| Error    | 错误图标、原因、保留草稿、重试                  | 180ms 淡入                               | 不摇晃，不清空；失败读屏只通知一次                            |
| Disabled | 明确降低对比的既有样式，仍可读                  | 无动作动画                               | 不显示假进度，不触发按压缩放                                  |
| Focus    | 键盘导航以底色 / 文字强调定位，无外描边         | 当帧                                     | 与 Hover 独立；自动聚焦和指针操作不额外强调                   |

播放 / 暂停只做同位置图标交接，不用复杂路径 morph；读屏名称在实际状态变化时同步。开关轨道与滑块 120–180ms 接手，但请求失败必须回到真实状态，并显示错误原因。

## 弹窗、菜单与手机底部层

- 弹窗先定位到最终几何位置，再播放视觉进入；不在定位 transform 上叠加会冲突的动画。桌面面板保持 12px 圆角，手机底部层 16px。
- 遮罩不加装饰性模糊；面板入场与遮罩并行，禁止先等待遮罩完成。取消、Esc、系统返回关闭；危险确认默认聚焦取消，普通表单聚焦标题或首个需要输入的字段。
- 真实模态层使用焦点约束和背景 inert；退出意图当帧被接收，背景恢复时点与焦点恢复配套，不能等固定超时误关新弹窗。快速重开取消旧退出回调。
- 嵌套配置优先同层替换内容；确需二级保护弹窗时不叠加多个高浓度遮罩。当前层退出后恢复上层焦点。
- 工作区 / 会议菜单在可用空间里向右、向左或向上展开，方向由最终定位决定，长度不挤动任务区。子菜单保留鼠标穿越间隙与键盘路径。
- 手机重点时间在打开表单时记录，备注可留空、最多 200 字，沿用现有 `mark` 指令。动效不能改变持久化字段或自动暂停录音。
- 原生权限、分享和系统更新使用平台呈现，不覆盖一层自绘过渡。键盘、系统字体、安全区和侧滑返回优先于固定示意尺寸。

## 实时内容与后台任务

### 字幕、智能笔记、新增行

已确认字幕整句 120ms 淡入，不逐字打字，不反复播放旧段落。临时字幕继续原位替换，不当作每次新增的正式行。正在跟随最新时保持底部锚点；用户翻看旧段落时不自动滚回。重点与 AI 采纳的强调落在真实新增内容上，而不是让整个编辑器闪烁。用户输入期间不移动光标，不更改编辑选区。

AI 手动 / 适度模式只在用户点击加入后强调已写入段落；主动模式沿用用户停笔后追加。状态切换重置旧预览，关闭功能停止演示。不能先画成“已保存”再补业务请求。

### 录音、下载、精修、纪要、翻译、更新

录音红点保持静态，配真实计时和状态文字。波形只表示真实输入，不能从静音编造活动。暂停时波形回到静态状态，真实录音数据与后台恢复遵守现有逻辑。

进度轨道使用现有 6px 样式与左侧锚点，事件驱动；最多 120ms Linear 插值到新的真实百分比，禁止把未知进度补成逐渐逼近 99%。未知阶段显示“处理中 / 等待连接”，减少动态效果下用静态图标与阶段文字代替循环。

任务完成在原任务区原位交接为勾号与完成文字，正文按用户当前上下文更新；不自动打开模态窗，不抢占正在阅读的标签。下载关闭只是隐藏、精修关闭可能取消、录音不能因隐藏丢弃等既有语义不变。任务收起和 72px 侧栏沿用当前汇总入口，不新增任务中心。

新增 / 删除任务对当前可见列表做稳定锚点处理；当用户正在操作某卡片时保留焦点、滚动和按钮位置。禁止对每次百分比更新做整卡入场或高度动画。输入、录音、播放和滚动的流畅性比任务卡过渡优先。

## 引导与官网

现有五步引导、左侧录音 → 转写 → 纪要的固定锚点保留。轮播属于低频品牌解释，允许有克制的编排；右侧真实表单、校验和下一步不等待轮播。当前既有 9 秒时间轴 / 1.35 倍播放不是新增性能或处理时间承诺。

引导右侧主动性选择采用 180ms 选中底运动；左侧品牌轮播沿用现有内容。生产轮播的窗口隐藏暂停、离页销毁、减少动态效果显示静态录音帧要求继续有效。不恢复独立“功能演示”第六步。

官网既有产品 / 协作演示继续作为营销内容；只在可见时运行，暂停状态有稳定画面，减少动态效果显示可读终态。导航、下载按钮、语言菜单采用同一反馈规范；阅读段落不逐屏飞入，不加视差与装饰性循环。没有必要为一致性重写现有演示时间轴。

## 减少动态效果、无障碍与性能

| 类型               | 常规                | 减少动态效果                              |
| ------------------ | ------------------- | ----------------------------------------- |
| 导航               | 短横移、交叉淡化    | 无位移，直接替换或 80ms 淡化              |
| 标签、开关、选中底 | 指示跟随目标        | 当帧就位，选中语义同步                    |
| 弹窗 / 底部层      | 轻缩放 / 滑入       | 无缩放、滑移，仅 80ms 层级淡化            |
| 按压               | 小幅缩放 / 轻回弹   | 背景与边框确认，触控范围保持              |
| Loading / 配对     | 局部循环图标        | 静态状态图标 + 明确文字；必要进度继续更新 |
| 新内容             | 淡入 + 一次底色强调 | 直接出现 + “新增内容”文字标记，不闪烁     |
| 保存 / 完成        | 图标淡化接手        | 状态文字和图标直接更新并持续              |
| 首启 / 官网        | 既有受控时间轴      | 可读静态帧；保留真正可操作入口            |

Web 使用 `prefers-reduced-motion`，手机使用 `MediaQuery.disableAnimationsOf(context)`，系统设置运行中变化应立即停止非必要运动。默认跟随系统，不持久化覆盖用户的系统偏好。

读屏不在每一帧播报。进度提供语义百分比，保存成功与失败在事件点播报一次；错误不仅靠颜色。关闭后恢复触发点；隐藏内容不可留在焦点顺序。按钮原有 40–44px 桌面高度、手机至少 48px 触控范围不缩小。浮层沿用真实模态焦点约束，非模态菜单不将整个文档设置为模态。

优先 transform、opacity 与小区域颜色变化；不逐帧改变 width、height、top、left，不常驻 `will-change`，不使用大面积 blur 或全屏阴影动画。已存在的运行时无需增加依赖。动画对象、RAF、计时器、监听器随作用域清理；窗口隐藏即暂停演示，返回时不自动重播业务成功反馈。

目标为主流 60Hz 设备上操作反馈下一帧可见、动画不引入超过 50ms 的主线程长任务；该项为后续生产集成性能验收目标，本轮没有进行真机帧率或高刷新率性能认证。

## 2026-10-17 连续性修复

引导语言、权限、模型与存储、AI、手机连接共五步共用不透明壳层。下一步准备期间保留旧页，准备失败恢复旧页操作；新页挂载后再移除旧页。前进正文+24px / 280ms、返回-24px / 180ms，正文透明度始终为1。语言文案当帧更新；按钮、选择、输入沿用公共反馈，减少动态效果直接就位。入场样式在首次绘制前就绪，禁止requestAnimationFrame后才补透明入场。

桌面同级与页内正文取消整块淡入，由选中态表达切换；父子短移不降低正文透明度。手机引导、主标签和详情标签保留退出正文直到交接完成，旧层停止ticker且不参与点击、焦点或读屏，避免AnimatedSwitcher只布局current造成首帧空白。

## 1.3 首次入场、焦点与模型设置交接

桌面主窗口与独立字幕窗口统一去掉系统外描边，覆盖标题自动聚焦、配对弹窗关闭按钮、输入容器与动态创建控件。保留真实焦点与模态约束；Tab / 方向键导航时，以底色与文字下划线表达控件位置，输入框以底色和边框颜色表达，复选框 / 单选框强调所属标签。指针操作退出键盘强调模式，不取消键盘、读屏或焦点恢复。

模型设置的下一步先完成存储操作并关闭迁移浮窗，再挂载AI页。只有操作超过180ms才显示迁移进度，等待期间背景始终inert；快速保存不插入短暂的原生模态遮罩。成功、失败均恢复原inert状态，重复提交继续被阻止。

首次点击“开始使用”（或“稍后”完成引导）时，工作台在引导层下就绪并可操作，引导260ms向上12px / 缩至.99退出，会议库保持不透明并从下方16px于520ms就位，侧栏从左侧12px于420ms就位，均用Ease Out。引导退场完成即移除覆盖层；后续任何点击或键盘输入结束整组动效。复用既有首次完成标记，不增加持久化字段。再次完成引导不重播；减少动态效果 / 隐藏窗口直接进入终态。首次入场、输入中断、不重播与减少动态效果由桌面端到端测试覆盖。

## 1.4 会议详情三标签统一

D10 / D11 / D23共用相同的单栏主区、标题字号、页头高度、正文边界和固定播放器；移除笔记 / 逐字稿右侧的重复纪要预览及逐字稿专属紧凑页头。导出固定在页头，三种内容统一180ms Ease Out、向上6px就位，正文始终不透明；连续切换取消旧面板动效，减少动态效果直接接手。编辑器节点及草稿仍保留，隐藏面板不参与点击与焦点。

参会者移至共享页头，默认显示前3位姓名与头像、剩余人数，所有标签都可打开完整名单并搜索。长姓名省略显示，完整姓名在名单中可读；没有参会者时不显示空行。去掉参会者分隔线、纪要外框及章节重复横线，以留白划分内容；保留标签导航与播放器边界。搜索结果以主区内浮层展示，不因搜索改变阅读区列宽。
