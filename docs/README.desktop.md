# 桌面录音与悬浮胶囊

## 开始录音

- **快速录音**：沿用上次会议的语言、识别模型、说话人数、翻译目标与工作区，沿用最近成功录音的采集来源。首次使用默认采集麦克风与系统声音，并使用多语言混说；缺少模型时会提示准备模型。
- **开始录音**：先选择本次会议的采集来源、语言与模型，再开始。已有音频可通过导入入口处理。
- **浏览其他会议**：侧栏显示当前录音的状态、计时与返回入口，历史会议的播放与当前录音分开控制。

macOS 14.4 及以上仅申请系统音频录制权限，无需授予屏幕录制权限；macOS 14.0–14.3 仍使用屏幕与系统音频权限。若曾拒绝授权，请在系统设置中重新开启。 系统音频权限无法由公开接口静默查询时，界面显示“录音时确认”，不会把静音误判为拒绝。

在 **设置 → 通用 → 会议录音提醒** 可控制后台提醒。支持飞书、Lark、i讯飞、讯飞会议、钉钉、企业微信、华为云会议、Zoom、腾讯会议（含 VooV Meeting）、Discord、Slack、Teams 和 Webex。桌面客户端发声时，Brevia 在屏幕右上角显示提醒。点「开始录音」沿用最近配置，点「取消」收起。原生应用按发声进程识别，同一客户端里的消息提示音、语音或视频播放也可能触发。macOS 需要先在设置中确认过系统声音权限。网页提醒要求同一浏览器有声音且存在可见、标题含有效会议代码的 Google Meet 窗口。仅看 YouTube、B 站或使用网页麦克风不会触发。macOS 无法读取窗口标题时跳过网页提醒。若同时打开符合条件的 Meet 窗口，其他标签的声音可能因共享音频进程触发提醒。

在「自定义会议应用」中选择本机已安装的会议客户端。macOS 选择应用程序，Windows 选择发声客户端的 EXE，按其完整安装路径匹配；移除应用后会停止该自定义匹配。浏览器沿用网页会议识别规则。

## 全局快捷键

在 **设置 → 通用 → 全局快捷键** 配置。默认 macOS 为 `⌥⌘R`，Windows 为 `Alt+Ctrl+R`：空闲时快速录音，再按一次结束并保存；保存失败时可再次按下重试。暂停／继续可另设组合键，默认关闭。

点击要修改的快捷键或“未设置”，然后按下新组合键。组合键需包含 Ctrl、Alt 或 Command，支持字母、数字及 F1–F24。按 Esc 取消，按退格或 Delete 清除。也可以用同一行的清除和恢复默认按钮。遇到冲突时，Brevia 会提示并保留原快捷键。

Brevia 运行时，无需切换窗口即可操作；正常触发保持当前应用焦点，菜单栏状态和录音胶囊提供反馈。初始化、启动、保存和按键编辑期间不会重复触发。缺模型或操作失败时显示主窗口，按提示处理模型、权限或保存问题。

## 使用胶囊

录音或回放期间，启用自动胶囊后，只有最小化主窗口才会显示胶囊。恢复主窗口时胶囊立即收起；切换到其他应用或将窗口隐藏到托盘时，录音和回放照常进行。

- 拖动胶囊调整位置，点击左侧电平按钮返回当前会议。
- 查看录音时长，暂停、继续或结束录音。
- 将指针停在时钟或字幕按钮上可预览，移开后自动收起。点击字幕按钮可固定展开，再次点击或按 Esc 收起。展开时可用图钉切换固定状态，用方向键切换页签。
- 上翻字幕时停止自动跟随，点击字幕区的下箭头回到最新内容。
- 在「笔记」页签查看、采纳或忽略 AI 建议。录音或回放时点「编辑」即可输入 Markdown 或粘贴图片；点「保存」或按 ⌘/Ctrl + Enter 将修改写入这场会议。若主窗口已有新修改，胶囊会保留当前输入供你复制、核对。

录音胶囊预览最近 80 段字幕，回放胶囊可滚动查看整场字幕。暂停时电平与识别动画停止；保存失败时保留重试入口，保存成功后胶囊短暂确认并收起。

主窗口最小化后，可从菜单栏或托盘手动显示或隐藏本场会议的胶囊。新会话重新使用自动胶囊偏好。

## 隐藏与退出

在 **设置 → 通用** 中配置关闭主窗口的行为、菜单栏／托盘图标的显示时机和自动胶囊。

默认关闭主窗口即退出，菜单栏／托盘图标始终显示，自动胶囊开启。选择“隐藏”后，关闭主窗口会继续录音，可通过 macOS 菜单栏或 Windows 托盘恢复。

要真正退出，请使用菜单中的退出操作。录音中会先确认是否结束并退出，确认后等待录音保存。保存失败或存在尚未处理的编辑时会保留窗口与恢复入口，请先处理提示再退出。

## 查看与整理结果

- 实时转写与笔记并排显示。会中「查找与替换」浮在工作区右上方，两栏保持原宽。新确认的字幕会更新匹配列表；可勾选要替换的文字。
- 会后纪要可继续编辑、复制与导出，需要时回到逐字稿或录音核对原话。
- 参与者名单随「原始／精修」稿切换，按当前稿件中实际发言的人统计。点击会议标题下的参与者，或逐字稿里的头像、姓名，可选择「只看此人发言」或「重命名本场说话人」。也可从该段「更多」或正文右键菜单选择说话人。点击正文上方的姓名标签即可清除筛选。只想改单段时，在该段工具条选择「标记说话人」。
- 已保存录音但缺少本地 AI 模型时，可先查看逐字稿；下载模型后再整理纪要。

更多功能与下载入口见[项目介绍](../README.md)，手机配对与录音恢复见[手机指南](../mobile/README.md#手机会议与桌面联动)。

在 **设置 → Agent 与 MCP** 复制引导语发给本地 Agent，或复制 MCP 配置加入客户端，即可调用会议检索、转写、翻译和录音控制。详细行为见[设置说明](../DEVELOPMENT.md#设置中的-agent-管理)。
